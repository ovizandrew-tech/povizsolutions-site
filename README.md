# Poviz Solutions website

Company website for **povizsolutions.com**, hosted on Netlify.

- `index.html` – homepage (products, services, about, demo request form)
- `thanks.html` – page shown after the demo request form is sent
- `favicon.svg`, `robots.txt`, `sitemap.xml`
- `netlify.toml` – tells Netlify to publish this folder as-is (no build step)

The demo request form uses Netlify Forms (form name: `demo-request`).
